# 三项分析脚本说明

本目录保留数据清洗、社会网络分析和K-means聚类三个脚本，论文编码信度由 SPSS完成。


## 运行环境

在项目根目录执行：

```bash
pip install -r requirements.txt
```

## 1. 数据清洗与口径核验

```bash
python3 "analysis/clean data.py"
```

脚本读取 `知情代理人21-25年发帖清洗及转发均值.xlsx`，完成字段统一、账号 ID 规范化、日期和年份校验、关键字段过滤、互动量非负处理、疑似重复标记。疑似重复必须结合帖文 ID 或链接人工复核，脚本不会仅凭正文相同自动删除。

如确需在本机导出逐条规范化数据，可加入 `--write-row-level`。

## 2. 社会网络分析

表 5 的关注网络需提供逐年关注边表和 206 个样本节点名册：

如果2021—2025年分别保存在五个文件中，可将文件放入同一私有目录，并确保文件名含有对应年份；脚本会自动识别并一次计算五个年度：

```bash
python3 analysis/network.py \
  --follow-edges "/本机私有路径/follow_edges_by_year/" \
  --nodes "/本机私有路径/nodes.csv"
```

评论网络使用：

```bash
python3 analysis/network.py --comments "/本机私有路径/comments.csv"
```

脚本计算有向网络密度、平均路径长度、聚类系数、Louvain 模块度、相互关系占比，以及度、中介和接近中心性。路径长度与聚类系数同时给出明确命名的有向、无向口径，便于与 Gephi 的具体参数设置核对。关注和评论关系不会混合，同一年度的重复关注边会自动合并为一条。

节点中心性与加权边默认不导出。

## 3. K-means 角色聚类

```bash
python3 analysis/cluster.py --features "/本机私有路径/account_features.xlsx"
```

账号特征表一行一个账号，默认严格检查 206 个账号。变量按论文方法分为三组，列名使用相应前缀：

- 发帖时间分布：`time_*`，例如 `time_formation_share`、`time_development_share`、`time_dissipation_share`；
- 内容类型占比：`content_*`，例如 `content_fact_share`、`content_emotion_share`、`content_commentary_share`；
- 网络中心性：`centrality_*`，至少包含实际采用的度、中介和接近中心性；
- 校验字段：`account_id`、`identity_type`。

严格要求三组变量同时存在。脚本先进行 Z 标准化，再计算 k=2—6 的肘部指标和轮廓系数，设定选择 k=3，最后计算调整兰德指数。

第一次运行后，应检查 `cluster_profiles_zscore.csv`，根据三个簇的实际行为中心进行后验命名；确认后可再次运行并传入：

```bash
python3 analysis/cluster.py \
  --features "/本机私有路径/account_features.xlsx" \
  --role-map "0=触发者,1=偏引者,2=散逸者"
```

本目录只提交分析程序和方法说明，不附关注边表、账号特征表、逐条编码表或脚本运行结果。论文统计结果以正文和最终统计口径为准，关键原始数据由研究者本地保存。
