# X 平台数据采集工具与课程研究项目

本项目包含一套基于 Selenium + Chrome 的 X 平台公开数据采集工具，以及使用该工具和历史整理数据完成的课程研究：

> **境外社交平台涉华舆情知情代理人的识别与网络互动——基于 X 平台涉疆议题 2021—2025 年的纵向研究**

项目包含从工具开发、故障修复、数据采集、清洗核验、网络分析、图表迭代到论文定稿的完整过程。

## 一、主要成果

- 初始候选账号：1,128 个
- 总体有效账号：557 个
- 知情代理人子样本：206 个
- 有效涉疆帖文：4,952 条
- 分年度关注关系：4,127 条
- 直接评论记录：5,312 条
- 评论倾向复核样本：1,369 条
- 观察期间：2021-01-01 至 2025-12-31

206 个知情代理人包括社会活动型 117 个、学者型 43 个、普通用户型 46 个。最终论文综合使用内容编码、社会网络分析、K-means 聚类和事件阶段比较，讨论身份结构、行为节律、网络演化、角色分工与传播效能。

## 三、安装

建议使用 Python 3.11 或以上版本，并安装 Google Chrome。

```bash
pip install -r requirements.txt
```

第三方依赖按课程项目的完整流程分为：

| 库 | 用途 |
|---|---|
| Selenium | 控制 Chrome，读取 X 页面并采集公开帖文和评论 |
| undetected-chromedriver | 可选驱动模式，默认关闭 |
| pandas、NumPy | 表格清洗、分组汇总和数值计算 |
| openpyxl | 读取和写入课程数据使用的 Excel 工作簿 |
| SciPy、scikit-learn | 统计计算、标准化和 K-means 聚类 |
| NetworkX | 构建关系网络并复核网络指标 |
| Matplotlib、Seaborn | 绘制和美化统计图表 |
| Pillow | 整理截图、媒体证据和联系表 |

命令行、CSV、JSON、日期、正则和 URL 处理使用 Python 标准库。Gephi 0.10.1 用于关注网络和评论网络可视化，属于外部桌面软件，不写入 `requirements.txt`。

## 四、快速开始

```bash
python3 x_scraper.py config
python3 x_scraper.py tweet <帖文ID>
python3 x_scraper.py timeline <账号> --count 50
python3 x_scraper.py search "Xinjiang" --count 50 --product Latest
python3 x_scraper.py account-search <账号> --since 2024-01-01 --until 2025-12-31
python3 x_scraper.py replies <帖文ID> --count 30
python3 x_scraper.py report <账号> --since 2024-01-01 --until 2025-12-31
```

`config` 命令会生成配置模板。真实 `config.json` 和 `x_cookies*.json` 只用于本机，不出现在 Git 或最终提交包中。

三项分析脚本的参数、私有数据字段和运行示例见 `analysis/说明.md`。脚本默认只写出汇总指标，不复制逐条帖文、关系边或账号聚类归属。

## 五、工具的关键改进

爬虫经历了从 twikit 原型到 Selenium 成品的多轮迭代，主要改进包括：

1. 精确校验目标作者，避免把推荐帖或其他账号内容归给目标账号；
2. 统一 UTC 至北京时间的日期判断，并把日期停止判断放在关键词过滤之前；
3. 使用首屏异步等待、小步滚动和显式等待，减少漏抓和过早停止；
4. 展开 X 的“显示更多”正文，遍历文本节点并保留表情与后续文本；
5. 隔离主帖与引用帖，保留稳定帖文 ID、原始链接和媒体证据链接；
6. 在推荐区边界前核对对话链，区分页面回复数与实际可见评论数；
7. 使用稳定 ID 去重、公式注入防护、输入校验、限流和导航重试；
8. 为作者、日期、关键词、正文完整性、评论归属和 CSV 输出建立回归测试。

详细过程见 `fix_log.md`，长期规则见 `CLAUDE.md`。

## 六、输出与数据口径

帖文 CSV 使用 UTF-8 BOM，主要字段包括作者、账号 ID、时间、正文、回复、转发、点赞、浏览、帖文 ID、原始链接、媒体数量和媒体链接。评论 CSV 保留评论者、评论 ID、原始链接、时间、正文、目标账号和对话链信息。

论文最终统计统一以：

```text
data/整理版最终数据/论文最终统计口径.csv
```

为入口。过程母表、原始 CSV、试验文件和历次图表仍保留，以展示清洗、复核和视觉迭代过程。遇到旧版过程数字与论文终稿不一致时，以最终统计口径、终版图和论文为准，并在 `清洗报告.md` 中查看差异说明。

## 八、安全与研究伦理

- Cookie 等同于登录凭据，禁止提交、上传或写入截图和日志；
- `data/` 不进入 Git 历史，但最终课程压缩包应单独保留；
- 只采集公开可见且研究所需的数据，不绕过权限或使用高频并发；
- 网络指标和公开行为用于研究分类，不用于断言个人受雇、违法或存在未经证实的组织关系；
- 最终打包后应重新解压，并运行 `git log --oneline --all` 确认 `.git/` 完整。
